PR-Agent 代码审查

Exposed Secret

The committed `FIGMA_ACCESS_TOKEN` is a live-looking credential in a tracked environment file. Anyone with repository access can use it; revoke it and move it to a CI secret or untracked local environment file.

CAPTCHA Bypass

The session-storage marker is checked in production client code and skips CAPTCHA for any visitor who can set it in their browser console. This makes the automation-only bypass available to arbitrary users; gate it behind a test-only build or remove it from production builds.

Lost Currency

`buildBankReceiverFormValues` does not map `receiverKyc.bankCurrency` into the form values. When an existing receiver is edited, the currency selection is therefore lost; saving can submit an empty or fallback currency and overwrite the receiver’s stored currency.

Attachments Dropped

When the selected receiver is a person, `receiverInfo.receiverCompanyKyc` is absent, so uploaded attachments are never included in the order payload. This silently loses attachments for personal receivers even though the attachment flow accepts them.

Deep Link

The tab is initialized from `router.query` only once. On client-side navigation or initial hydration, the query may not be populated at that point, so `?tab=remittance` is ignored and the remittance tab never becomes active. Update the tab when the router is ready and the query value changes.
