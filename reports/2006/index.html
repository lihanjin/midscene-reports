PR-Agent 代码审查

CAPTCHA Bypass

Any user can set this sessionStorage key in their browser to skip the CAPTCHA for any non-exempt tenant. Because this is a client-side check, it cannot safely distinguish E2E automation from a real user; keep the bypass out of production code or enforce it through a trusted server-side mechanism.

Exposed Token

This adds a Figma access token to a tracked environment file. Anyone with access to the repository can use the credential; revoke it and move it to a protected secret store, ensuring it is not committed.

Missing Prefill

Editing an existing receiver does not restore `bankCurrency`: this mapping restores the other newly added bank fields but omits it. The currency field will therefore be blank (or fall back to a default) when editing, and saving can change or lose the receiver’s previously selected currency.

Unhandled Failure

For credit accounts, the current dialog is removed before `accountOverview` and `preCalcMortgageDeductDetail` complete. If either request rejects, no cancellation dialog is shown and the user receives no error feedback, leaving them unable to continue from this flow.

XSS

Agreement HTML is inserted directly with `dangerouslySetInnerHTML`; removing a text color style does not sanitize markup. If an agreement resource contains a script-capable element or event-handler attribute, opening the preview can execute it in the application origin. Sanitize the HTML before rendering, even if the current source is intended to be trusted.

Stale rate

Disabling the next-step button when `exchangeRate === '-'` can leave the user permanently unable to continue if `queryRemittance` succeeds but returns `-` as its rate (or legitimately has no rate for the selected currency). There is no fallback or error action in this component for that state.

Lost translation

`purposeOptions` are translated with `t(option.labelKey)`, but the previous code rendered `option.label`. If these options are built with a display label rather than a translation key, the dropdown will show the key (or a missing-translation message) instead of the purpose label.

Attachments Dropped

Attachments are added only when `receiverInfo.receiverCompanyKyc` exists. For a personal receiver, that condition is false, so the uploaded files are silently omitted from the order submission even though the UI accepts them. Include the files through a submission field that supports personal receivers, or prevent uploads for that case.

Deep Link

Next.js often renders this page before `router.query` is populated. Because `activeTab` only reads the query in its state initializer, `?tab=remittance` can then leave the page on the transaction tab for the component's lifetime. Sync the tab when the router is ready or the query changes.
